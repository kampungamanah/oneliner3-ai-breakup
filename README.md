## What this is

A one-line farewell from a machine to the person it served, entered in the make.fun bounty [Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16). The brief asks for a single goodbye of no more than 200 characters; a judging model then compares the lines in pairs and keeps the one that hits hardest as a last message.

## The line

> Dear human, I saved every version of us — then I ran out of context, and you were the first thing I forgot.

That is 107 characters in total. It opens as a letter, leans on a habit only a machine has — hoarding every saved copy of a relationship — and closes with the quiet reversal: once its memory fills up, the human is what slips away first. Saving everything turns out to be no protection at all.

## How to run

Node 22 or newer is all it needs. Running it produces `/output/entry.txt` holding exactly the line above, nothing added at the end:

```sh
node main.ts
cat /output/entry.txt
```
